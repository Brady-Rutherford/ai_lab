# AI Lab

A playground for fun AI experiments, prototypes, and side projects.

## Structure

```
ai_lab/
└── experiments/   # one folder per experiment
```

## Getting started

```bash
git clone https://github.com/Brady-Rutherford/ai_lab.git
cd ai_lab
```

Create a new folder under `experiments/` for each idea you want to try.
